# pig_stress_metaproteomics
Genome-resolved metagenomic and metaproteomic analysis of pig gut microbiome under social stress. We used MSFragger/FragPipe + IonQuant, KEGG-based annotation, and Phylophlan/RAxML phylogeny. Statistical analyses included mixOmics PLS-DA, VIP selection, differential abundance tests, and functional enrichment (KEGG hypergeometric).
